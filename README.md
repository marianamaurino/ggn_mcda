# ggn_mcda

GoGreenNext WP6: multi criteria decision analysis (MCDA) of urban greening priority in Malta and
Klagenfurt, weighted with a citizen budget allocation survey. ISGlobal.

- Code: `mcda/` (file index in `mcda/README.md`; methods spec `mcda/MCDA_paper_results_spec.md`;
  decision history `mcda/CHANGELOG.md`).
- Shared plotting and survey helpers: `R/`.
- Data and outputs are not in this repository. On the ISGlobal server, `data/` and `output/` are
  symlinks to `../ggn_analysis_archive/`, shared with the health impact assessment repository
  `ggn_analysis`.

Split from `ggn_analysis` on 26 November 2026; the history of the `mcda/` folder is kept.
